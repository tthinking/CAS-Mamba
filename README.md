# CAS-Mamba: A Fully Content-Aware Image Fusion Network via Semantic Sorting and Balanced Optimization (Information Fusion 2027).

This is the official implementation of the CAS-Mamba model proposed in the paper ([CAS-Mamba: A Fully Content-Aware Image Fusion Network via Semantic Sorting and Balanced Optimization](https://www.sciencedirect.com/science/article/pii/S1566253526008456)) with Pytorch.
